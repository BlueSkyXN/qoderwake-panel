# 0.11 修复与现场验收

2026-10-03。面板 **0.11.0** 已部署；Linux CN daemon 验证基线仍为 **1.1.6**。本轮针对此前只读复查确认的缺陷，不代表全部产品目标完成。

## 网关：预检、代际切换与恢复

- Panel 与网关共用 `panel/gateway_policy.py`，兼容已使用的 `token_allow_prefixes`，拒绝未知键、错误模式和畸形规则，不退回 observe。
- `ops/gateway-manager.py` 把网关源码、策略模块、配置保存到 `$QW_ROOT/gateway-runtime/` 的独立代际目录。目录 750、文件 640，由 root 和网关用户组控制；当前运行记录 600。
- 先以实际网关 UID/GID 做 `--check`，验证代码、配置可读与日志可写，再停止已确认身份的旧进程。不会自动创建用户、退回 root 或批量 `pkill`。
- 运行身份用 PID、启动脚本、随机 nonce 和源码/配置哈希核验；健康检查只证明本机指定代码与策略正在运行，不证明官方链路成功。
- 新代启动或发布失败恢复上一代；回滚发布失败恢复当前代。保存配置与状态记录是分别原子写，已覆盖异常恢复，**没有断电恢复日志，不承诺跨文件崩溃原子性**。
- Linux 隔离端口真实完成 strict 空规则启动、切到 enforce、回滚、注入新代启动失败并恢复，测试不向官方发请求。连同权限、未知进程拒绝、发布失败和畸形请求测试，共 13 项通过，无子进程清理警告。
- 生产的旧网关尚未迁入代际管理。配置权限已修正为 root:网关组 640，实际用户读取和预检成功，但**没有停止或替换生产旧网关**。页面显示运行策略“未核实”，不再用保存值冒充生效值，并禁止自动应用规则。首次迁移及生产网关回滚仍待专门验收。

标准目录和扁平部署均需随包包含 `gateway_policy.py`、`gateway-manager.py`。发布检查已加入必需文件，并拒绝发布 `gateway-runtime/`、备份和补丁运行数据。

## 交互与后端修复

- Artifact 改用携带当前 Cookie 的原生下载链接，修复动态按钮没有绑定事件的问题。先核对会话产物清单，再请求固定 daemon 文件地址；限制 32 MiB，强制附件与二进制 MIME，禁止路径/查询/片段注入。
- Skill 使用机器人与技能下拉，不要求手输 ID。官方正文 404 转为正常只读状态，认证和权限错误不再混成 502。只读、固定技能或缺版本基线不能写入/回滚；保存保留原始空白并核对当前版本。
- 会话列表、自动化列表、运行历史和待审批列表贯通页码/offset。切机器人或来源重置会话页码；异步返回不会覆盖已切换页面。
- 浏览器实测发现确认窗口关闭后 Promise 未完成。确认处理改为在 submit/cancel 时直接完成，外部 close 一律视为取消，避免依赖滞后的 close 事件或复用上次确认。
- IM 新通道后端默认停用，编辑省略 enabled 时保留既有状态；补齐动态取消按钮绑定。明确提示编辑运行中的通道可能立即重连。
- 配对批准前重新读取待审批页，核对 pendingId、revision、身份字段、有效期和目标 Waker；不信任浏览器传回的名称。已覆盖变更、过期、缺失请求拒绝。**官方 1.1.6 本地批准 handler 未提供 pendingRevision 原子比较，重读与写入间仍有竞态窗口；没有真实 IM 审批验收，不称完整原子审批闭环。**

## 默认关闭已实际生效

- SDK flag 旧入口也改为统一控制器包装，所有当前支持入口缺省 `QODERWAKE_HOT_DEPLOY=0`、`QODER_MEMORY_DISABLE_EMBEDDING=1`。
- 生产应用前两次确认无运行任务，备份原启动参数与完整环境到 600 权限文件；准确核对 daemon PID/启动时间后停止，只改变上述两个变量，保留网关端点、HOME、SDK BYOK 及 Provider 配置。启动或检查失败可恢复旧环境。
- 重启后的期望值与 `/proc` 实际值一致：自动热部署关闭、官方 memory Embedding 禁用，`pendingRestart=false`。Provider 配置哈希未变，两个 Waker 保留，目录当次返回 14 个模型；目录此前曾返回 13，不将动态数量变化归因于本轮配置。
- 重启后核验了健康、模型/Waker 目录、实际环境和技能读取，未再次发送真实模型消息，因此不将该只读检查称为重启后的聊天端到端验收。
- 这不等于完全锁版、不代表所有 Embedding 场景停止，也不新增通用 Embedding BYOK 或受保护业务免登录。
