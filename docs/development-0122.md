# 0.12.2 集中修复与统一验收

日期：2026-10-06。**当前为未发布、未部署的源码候选**；公开 Release 和参考生产 Panel 保持 0.12.1。此轮集中修复完成度检查中可在 Panel 内解决的问题，不把隔离测试写成生产迁管或真实业务完成。

## 修复范围

- **运行态三态**：`pendingRestart` 为 true / false / null，分别表示已核实不一致、一致、未知。缺失受管身份或 PID/端口核验失败不再报告“待重启”。模型页和运行策略页禁用未受管 daemon 的重启入口；服务端精确身份保护不放宽。
- **上行开关可配置**：增强管理加入会话投影与远程执行上行的继承 / 关闭 / 开启选择，保存期望策略、展示下次启动值与已核实的进程值。旧客户端保存其他开关不会丢掉已有上行策略；继承不抹掉启动环境。两个开关的功能代价明确显示，未配置不称已禁用；既有关闭项重新开启仍受控制器拒绝静默放宽的保护。
- **重启结果不再假成功**：运行策略应用通过统一 mutation 检查 HTTP 200 内的 `ok:false`，失败不显示重启成功。取消不保存、不重启。
- **状态页不再启动 N+1 个 CLI**：模型偏好读取改用已核对的官方 `/api/model-preferences/:workerId`，最多 4 个 HTTP 读取并发；账号展示只取 `/api/frontend-auth/me` 的名称，不使用会触发远端 profile 请求的 `/api/user/profile`。仍有逐 Waker 的 HTTP 读取，不称恒定请求数或 TCP 连接复用。
- **网关状态不误报停止**：未受管显示“未受管 / 未核实”，身份失败显示“身份或健康未核实”；不把保存的 enforce 当作运行策略。
- **日志尾部 I/O 有界**：只读完整记录，总窗口最多 1 MiB / 5,000 行，支持受管日志的轮转文件；旧大日志仅尾读、不改写、不清理。畸形 JSON 行跳过，不使整个接口 502。
- **受管网关日志轮转**：新日志位于 `$QW_ROOT/logs/gateway/uplink-gw.jsonl`，专用目录归网关用户、0700；文件 0600。单份 8 MiB、最多 3 个历史文件；跨线程/进程锁保护轮转，拒绝链接、硬链接、FIFO、异常属主或公开权限文件。历史旧日志原样保留；轮转必须运行新版网关才会生效。管理器 stdout 日志不在此轮转范围。
- **用量增量游标**：记录 inode/device、字节位置、首尾校验与重复事件序号，追加不重扫整文件；兼容旧事件表，重启、轮转和截断不清空计数。每请求正文读取最多 8 MiB、每文件 2 MiB，完整性、待扫描文件、跳过长行和不可读文件可见。首尾 guard 读取单独计量；不保证检测任意中间改写，也不是完整历史账单。
- **会话写入节流**：`seen` 最多每 60 秒持久化一次，但每次仍从数据库核对撤销、凭据和到期。空闲到期可能比最后请求提前不足 60 秒，不延长绝对有效期。
- **浏览器路由**：修复 hash 改变 / 前进后退不重绘；viewer 打开管理员深链接回到总览，不留下空白页面。
- **非 root 目录遍历**：Linux 逐层 O_NOFOLLOW 保护保持，父目录使用 O_PATH，只要求穿越权限，最终目录才要求可读；修复拥有合法 0711 父目录权限的非 root 网关启动失败。日志准备也拒绝 FIFO/硬链接，不在目标验证前改权限。
