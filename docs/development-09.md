# 0.9 开发记录

## 产品决策

- 维护者选择本阶段继续使用现有 HTTP 部署，HTTPS 不再列为功能待办；界面保留明文传输提示，代码能力不删除。
- 官方 memory Embedding 暂不优先，所有项目启动入口默认传入 `QODER_MEMORY_DISABLE_EMBEDDING=1`。可在增强管理显式打开。
- 自动热部署同样默认关闭；这只关闭官方自动轮询，不能阻止 root 或手工升级器。

## 本轮代码

- `runtime-policy.json` 不存在时默认 `{hotDeploy:false, embeddingDisabled:true}`；畸形文件 fail closed，不退回官方默认。
- `restart-panel.sh`、`qw-ctl.sh`、网关启动器及直连启动器统一默认值；由面板重启 daemon 时再读取已保存策略。
- 官方插件页增加已安装列表，并保留安装、卸载、启停二次确认。
- IM 页面增加 CN 版支持的飞书配置编辑、秘密留空保留、paired/open 权限、Waker 绑定、工件开关、独立保存/启动、删除。
- strict 网关增加离线策略候选生成器。路径只有在显式 `audit_paths` 或已批准规则中才进入日志；未知动态路径保持打码。候选必须经人工 approvals 文件才能生成 strict 配置，工具不直接激活服务器策略。

## 仍需现场条件

- IM 端到端需要平台 App ID/Secret、事件权限和真实消息；没有这些输入时只验收配置保密及官方 API 契约。
- 第三方插件安装会下载并执行代码；不选择未知插件做自动破坏性验收。
- strict 策略必须先完成冷启动、模型目录、至少两轮聊天和资源下载观测，再单独决定是否切换；实现存在不代表现场启用。
