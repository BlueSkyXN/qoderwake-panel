## 0.12.0 历史验收

- Provider 完整原始字节 revision、共享路径协作锁、单份恢复点和两阶段 probe 已实现；最终 rename 前再次校验，恢复点写入期间外部变化会拒绝覆盖。它不是针对非协作写入者的原子 CAS，编辑期间须另行暂停外部配置写入；复杂 Provider 只读，secret 不回显。
- Waker/Provider 删除依赖 preview、fresh rescan、impact digest、一次性 preview、目标级 unresolved lock、幂等 replay/status/reconcile 已实现；pending/unknown 均持锁且不自动重发 DELETE。单 Panel 进程内依赖写入与删除互斥，未决删除期间保守暂停新增依赖写入；不覆盖外部或多进程写入。必需源 null/畸形字段拒绝按空引用放行。
