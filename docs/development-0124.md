# 0.12.4：页面加载不再计算文件哈希

交付日期：2026-10-09。

## 改动

- 启动、重启和每次打开页面都不再计算受管文件的 SHA-256。此前每次页面加载都重读约 208MB 的 daemon 二进制，单次约 0.7 秒。
- 进程身份核对只比较路径、设备号和 inode。文件被替换后 inode 改变，核对仍会失败，不靠内容哈希发现替换。
- 内容哈希改为按需。增强管理页的「检查当前文件内容」由管理员触发，在后台线程计算面板解释器、面板脚本和 daemon 二进制，请求立即返回。结果对比状态记录中的哈希；记录缺失或为零值时显示「未记录」，不推断。
- 页面状态缓存从 15 秒延长到 60 秒。前端在此期间切换页面复用已取得的状态；写操作和手动刷新清除并重读。

## 验收

- 套件 247 项：macOS 245 通过 / 2 Linux-only 跳过。
- 生产实测：触发检查的请求 32 毫秒返回；后台完成后三个文件均与记录的 inode 和哈希一致。首次状态请求不再包含二进制读取。
