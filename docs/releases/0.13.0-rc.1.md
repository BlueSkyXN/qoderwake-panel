# QoderWake Panel 0.13.0-rc.1

这是 0.13 的首个预发布版本。主程序迁移到 Go，界面迁移到 React，面向共同维护同一 Wake 实例的人员。稳定版保持 v0.12.7。

## 主要变化

- 独立人员账号、角色和 Waker 范围；技能编辑、历史、差异、回滚及协作冲突处理。
- 373 项官方 CLI 操作，包含权限、实时参数契约、异步任务、交互输入与文件传递。
- 明文 BYOK 支持完整多模型 JSON 和扩展字段，密钥操作明确区分保留、更换和删除。
- Waker 的无项目默认、项目覆盖和会话实际模型分别展示，保存后核对回读结果。
- macOS arm64、Linux amd64 独立二进制，嵌入前端与 SQLite；原生服务配置和平台进程适配。

## 升级

先停止旧 Panel，保留程序、启动配置及完整数据快照；用副本和独立端口验证后再切换正式入口。账号数据库兼容既有格式。初始化首位人员管理员会停用旧共享 admin/viewer 登录，程序 caller key 保留。详细步骤见 [部署与回退](../deployment.md)。

新实例直接运行 Go 二进制。已有 schema1 Linux 网关保留 Python 兼容管理器，仍需要 `python3`；不会自动转换运行代际。官方 QoderWake、账号登录、系统凭据库和现有 Provider 配置继续由目标实例提供。

## 验证与限制

- CI 在 macOS arm64、Linux amd64 上执行 Go race、Python 兼容、JavaScript 和前端测试，构建并打包对应平台程序。具体结果以该标签的 GitHub Actions 记录为准。
- 本地浏览器使用合成配置验证了多模型 JSON 保存、项目模型偏好保存与回读、历史会话模型显示以及原生访问受限状态。
- 原生 BYOK 仍受 `MODEL_SETTINGS_LOCAL_ONLY` 等官方权限约束；没有原生凭据迁移功能。编辑旧明文 Provider 不会将其迁移到加密存储。
- 项目模型覆盖支持添加与更新，当前未提供删除覆盖或清空运行参数的入口。
- 目标 Mac 的部署切换、真实模型调用和 IM 业务验收尚未执行。发布本身不会修改运行中的实例。

项目许可沿用 PolyForm Noncommercial 1.0.0；第三方组件保留各自许可。
